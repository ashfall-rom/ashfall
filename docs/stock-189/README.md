# RP5 1.0.0.189 text artefacts

Text excerpts from the full `.168 -> .189` OTA
(`/root/archive/fota/rp5-ota/1.0.0.168-full-1.0.0.189.zip`,
sha256 `80f16fd5…4148f`). Generated by
[`scripts/firmware/`](../../scripts/firmware/) plus a throw-away payload dumper kept in
`/tmp` (not committed). No binary images, APKs or Retroid files are stored here.

| file | contents |
|---|---|
| `payload-manifest.txt` | parsed `payload.bin` manifest: 11 partitions, sizes, op types, dynamic-partition groups |
| `boot-fstab.txt` | `.189` first-stage `fstab.qcom` (from the boot ramdisk) |
| `boot-vbmeta.txt` | boot header, dtbo table, `vbmeta` / `vbmeta_system` AVB details |
| `kernel-summary.txt` | kernel version, key config, vendor module list, sample vermagic |
| `props-vendor-189.txt` | full `/vendor/build.prop` |
| `props-vendor-default-189.txt` | full `/vendor/default.prop` (VNDK etc.) |
| `props-of-interest-189.txt` | vendor/system property grep |
| `props-system-of-interest-189.txt` | display/treble/system props |
| `vintf-summary-189.txt` | vendor manifest target-level, HAL count, DCM |
| `fcm-summary-189.txt` | Android 17 FCM coverage vs `.189` target-level 5 |
| `rpsettings-sysfs-189.txt` | sysfs paths present as strings in the `.189` RPSettings APK |
| `rpsettings-sysfs-diff.txt` | `.189` vs `.31` RPSettings path-string diff |
| `fan-rgb-189.txt` | fan/RGB interfaces, mode->value mapping, smart curve, `.31` vs `.189` nodes |
| `mcu-gamepad-189.txt` | MCU UART frame, calibration file format, firmware/version diff |
| `init-rc-diff.txt` | vendor init fan/LED blocks and `common.rc` diff |
| `usb-diff.txt` | `init.qcom.usb.sh` differences |
| `apps-189.txt` | `/system` and `/system_ext` app lists |
| `package-diff.txt` | hashes/sizes of the Retroid apps/binaries that changed |

The analysis and the decision to stay on the `.31` base are in
[`../stock-analysis-189.md`](../stock-analysis-189.md).
