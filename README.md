<h1 align="center">AshFall</h1>

<p align="center">
  A LineageOS 24.0 (Android 17) ROM for the <strong>Retroid Pocket 5</strong>
  (Snapdragon 865 / SM8250).<br>
  Starts as a self-built GSI, grows into a full device ROM.
</p>

AshFall's built-in settings include a few advanced and diagnostic options that
are deliberately not advertised; they stay out of the way unless you look for
them.

- **Installing on a device:** the end-user installer lives in
  [`ashfall-rom/ashfall-install`](https://github.com/ashfall-rom/ashfall-install)
  (one command, checksum-pinned, no build tools). This repository is the source:
  build tooling, contracts and the hardware notes.
- Plan, decisions and repository contracts: [`docs/PLAN.md`](docs/PLAN.md)
- Shared config: [`config/ashfall.conf`](config/ashfall.conf)
- RP5 unbrick / restore-to-stock reference: [`docs/reference/rp5-recovery-guide.md`](docs/reference/rp5-recovery-guide.md)
